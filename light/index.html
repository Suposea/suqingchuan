About Me

关于我

深耕资金管理与市场风险领域的复合型专家

我是一名拥有十年银行资金与风险领域经验的复合型专业人士。 从美国北卡州立大学金融数学硕士毕业后，我一直深耕于金融机构的前中后台资金业务体系， 深度参与交易管理、市场风险计量、清算核算、估值定价、监管报送等全链路环节。

我的独特价值在于「业务 + 系统」双视角： 既理解金融市场业务的本质（衍生品定价、VaR 风险计量、FRTB 合规）， 又精通系统如何支撑这些业务落地（ComStar / Murex / Calypso / Summit）， 能独立承担需求侧的需求定义、模型验证与方案设计。

同时持有 CFA（特许金融分析师）、FRM（金融风险管理师）、 以及 信息系统项目管理师（软考高级） 三项核心资质， 具备 Python / R / SQL 量化分析能力，曾独立开发债券定价与风险分析工具。

近两年，我把业务洞察与 AI 工具结合，独立完成从 0 到 1 的产品落地： 自主提出需求、借助 AI 完成开发，再自行测试、部署与迭代—— 已独立上线市场动态周报系统与微信小程序，持续用 AI 把业务想法变成可运营的产品。
